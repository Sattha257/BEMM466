# ML Recommendation System for Personalized Early Childhood Education

MSc Dissertation — University of Exeter, 2025

## Overview
Designed a machine learning recommendation system to generate 
personalized learning strategies for early childhood education 
using K-Means clustering and Random Forest classification.

## Methods
- K-Means clustering for learner profiling
- Random Forest classification for strategy prediction
- Synthetic dataset of 800 learner profiles
- Python: Scikit-learn, Pandas, NumPy
